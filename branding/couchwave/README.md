# CouchWave artwork

Original CouchWave artwork created with the built-in image-generation tool on 2026-10-11. This replaces the provisional text-only beta artwork in the native app and browser tuner. The symbol is a coral couch surfing a teal wave; cream retro lettering and a midnight navy background form the app identity. No upstream logo pixels were used.

- `symbol.png`: transparent standalone emblem.
- `wordmark.png`: transparent horizontal emblem and lettering.
- `app-icon.png`: finished landscape Apple TV icon.
- `../../scripts/generate-couchwave-art.swift`: reproducible export into tvOS icon and Top Shelf asset sizes using the checked-in originals. Run at the repository root on macOS. The icon uses a single illustrated back layer and transparent foreground, rather than simulated depth.

The native `CouchWaveLogo` image set and browser `logo/couchwave-*` assets consume these files. No trademark clearance or registration is implied. The MIT license and Nostalgex attribution remain unchanged. Internal project/module names, stable data keys and archival upstream marketing material retain the original name for compatibility and historical accuracy.
